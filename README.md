# LanReel · 局域网素材放映厅

> 打开即看、同网分享、感知无延迟。选一个本地文件夹入库，立刻得到一条局域网链接；同事不用下载、不用账号，点开就能看片、勾选状态、写备注——文件始终留在你自己的机器上。

---

## 30 秒启动

```bash
node server/index.js      # 或 npm start
```

启动后终端会打印本机与局域网地址：

```
  LanReel 局域网素材放映厅  v1.7.0

  本机         http://localhost:8080
  局域网       http://192.168.1.12:8080   (en0)

  素材夹 1 个 · 素材 35 个 · 素材合计 1.26 GB
  项目目录实占 1.02 MB（挂载素材 1.26 GB 留在原处，未复制）
  数据目录     /Users/you/lanreel/data
  素材库       仅本机管理；同事用 /s/ 链接即可看
  机主口令   Xq7Ld2mPaRt4 — 在其他设备上管理素材库时输给你自己
  把上面的局域网地址 + 分享链接发给同事，同网即可秒开。
```

「素材合计」只是所有素材体积相加，「项目目录实占」才是 `data/` 真正吃掉的磁盘——挂载模式下两者能差三个数量级，别把源文件体积当成项目占用。源目录有读不到的文件时，这里还会多一行警告。

- **零依赖**：只用 Node 内置模块（`http` / `fs` / `crypto` / `os`），不需要 `npm install`，也不需要联网。要求 Node ≥ 20（开发验证于 Node 26）。
- **无需构建**：前端是原生 ES Module + CSS，浏览器直接加载，改完刷新即可。
- 换端口：`PORT=9000 node server/index.js`（端口被占用时会自动 +1 重试）。

## 核心流程

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 1. 入库 | 素材在本机：点「挂载本机目录 → 浏览…」选文件夹；素材在别处：点「选择文件夹上传」或整目录拖进来 | 挂载模式**不复制素材**，直接就地放映（`data/` 里只多出几张封面缩略图）；上传模式会把文件复制进 `data/`（浏览器拿不到绝对路径，无法引用原文件），边传边显示进度并本地抓帧生成封面 |
| 2. 生成链接 | 上传/挂载完成后自动弹出分享卡 | 得到 `http://<局域网IP>:<端口>/s/<分享码>`，一键复制 |
| 3. 同网浏览 | 同事在局域网内打开链接 | 秒开：`<video>` 直连本机文件，支持任意拖拽进度（HTTP Range） |
| 4. 勾选状态 | 勾选卡片（可 Shift 连选、⌘/Ctrl+A 全选）→ 底部操作坞点「待看 / 入选 / 需修改 / 淘汰」 | 批量写回，卡片左侧状态色带 + 署名 + 时间 |
| 5. 写备注 | 点开素材进入放映厅，边播边写备注 | 备注自动带上**当前播放时间点**，实时出现在所有在线的人屏幕上 |
| 6. 回到那一帧 | 点备注上的时间码（或进度条下方的刻度） | 画面跳到该时间点并**自动暂停**，方便对着帧核对意见 |
| 7. 出表交付 | 素材夹卡片 →「更多」→「导出评审表 CSV」 | 一张带状态、标注人、备注与时间码的表，Excel 双击不乱码；「导出完整记录 JSON」里另有这个夹子的操作流水 |

第 4、5 步产生的变化通过 **Server-Sent Events** 广播，同一局域网里其他打开页面的同事无需刷新即可看到卡片闪动更新。

## 功能一览

**入库与分享**
- 首页「开始使用」面板把两条入口并排摆出：**上传入库**（复制进 `data/`）与**挂载本机目录**（零拷贝），说明文字收进 ⓘ 提示
- 本地文件夹选择（`webkitdirectory`）/ 多文件选择 / 整目录拖拽（整个入库面板都能接住拖拽）
- **零拷贝挂载本机目录**：点「浏览…」直接弹出**系统原生文件夹选择器**（macOS `osascript` / Windows `FolderBrowserDialog` / Linux `zenity`·`kdialog`）拿到绝对路径并就地挂载，库里只记路径与元数据，`data/` 不再随使用量线性膨胀；也可以直接粘贴路径。源目录有新文件点「重新扫描」即可
- **挂载素材自动补齐元数据**：挂载时服务端不读文件内容，因此没有封面、时长和尺寸；打开素材夹时浏览器会用与上传完全相同的管线，从同源 `/api/stream/…` 读元数据并抓帧，回填视频封面 / 音频时长 / 图片分辨率（2 并发），并如实报数：补了几张封面、几个时长尺寸、几个浏览器解不了（解不了的提示转码后再入库）
- **源文件丢失会被标出来**：挂载的那条路径读不到文件时（被移动、改名、外接盘断开），开机校验一遍、供片失败当场补记，卡片变成虚线占位并标「已丢失」，素材夹与首屏汇总出「N 个源文件丢失」，放映厅直接说明原因；文件放回原位后点「重新扫描」自动恢复，已写的状态与备注全程不动
- **副本回收提示**：挂载完成后会自动比对，如果发现某个「上传复制」的素材夹内容与刚挂载的目录基本重合（≥90% 同名同体积），弹窗告诉你删掉它能回收多少磁盘
- **内容去重**：复制入库的字节按 sha256 归入 `data/blobs/`，素材夹里那份只是硬链接；同一素材反复入库只占一份磁盘，删除时链接数归零才回收，启动时另有一次孤儿清理
- 原始字节直传：无 multipart 解析、无临时缓冲、无云端中转，单文件上限默认 4 GB
- 客户端并发 3 车道上传，按 `相对路径 + 体积` 去重，重复文件自动跳过
- 视频/音频时长、分辨率在浏览器里探测（`<video>` 元数据），封面用 canvas 抓帧——**不需要 ffmpeg**
- 素材夹卡片：封面马赛克、状态分段进度条、评审完成度环、一键复制链接、追加文件；长标题一律省略号收在卡片内，操作按钮固定一排，重命名 / 导出 / 删除收进「更多」菜单
- **评审表导出**：卡片「更多」里一键下载 CSV（带 BOM，Excel 直接双击不乱码）——序号、文件名、相对路径、类型、时长、体积、状态、标注人、标注时间、备注（含时间码）、源文件是否丢失；完整记录 JSON 里额外带这个夹子的操作流水
- **操作流水**：谁在什么时候把哪条标成什么、加了或删了哪条备注、机主哪次改名/删除/重扫，每夹留最近 500 条，用于事后对账「这条是谁说不要的」

**浏览与评审**
- 区块标题与工具栏分行排布，标题右侧实时汇总「几个夹子 · 几个素材 · 几个为挂载 · 几个源文件已丢失」
- 首屏统计把「素材合计」和「data/ 实占」分成两个数字，各自带 ⓘ 说明挂载为什么会让两者差出三个数量级
- 成段说明统一收进 **ⓘ 悬浮提示**（悬停、键盘聚焦、触屏点击都能开，Esc 或点别处收起，带 `role=tooltip` / `aria-describedby` / `aria-expanded`）
- 卡片 / 列表两种视图，搜索、按类型与状态筛选、6 种排序（文件名一律数字自然序：`1、2、10` 而不是 `1、10、2`）
- 勾选支持 **Shift 连选**（锚点到当前整段选中/取消）、**⌘/Ctrl + A 全选可见**、**Esc 取消选择**；全选按钮三态显示当前可选数量
- 批量勾选 → 操作坞一次性打状态；放映厅内可单条打状态（键盘 1–4）
- 放映厅：视频 / 音频 / 图片 / PDF / 文本内联预览，上一条下一条、连续播放、下载原文件
- **时间码备注**：提交备注时自动记录当前播放位置（`@ 0:13`），可点时间码芯片改取当前帧、或点 × 改成不关联时间的「整体备注」；备注列表按时间点排序
- **点备注跳帧并暂停**：点时间码或播放器下方刻度条上的备注标记，画面跳到那一帧并自动暂停，对应备注高亮
- 备注带署名与时间，可删除自己的备注；卡片上显示备注数
- 实时同步（SSE）+ 断线自动重连，顶栏显示当前连着实时同步的**页面数**（含你自己开的标签页与弹层），分享页的同步角标断线时会变琥珀色
- 明暗双主题，署名与偏好只存在本机浏览器 `localStorage`
- **机主口令**：想在手机或第二台电脑上管理素材库，打开 `http://<本机IP>:8080` 时输口令即可（口令印在启动横幅里，「快捷键」面板里能复制）；评审同事永远不需要它

**素材类型**：视频（mp4/mov/webm/mkv/avi…）、图片（png/jpg/webp/gif/svg…）、音频（mp3/wav/m4a/flac…）、文档（pdf/txt/md/srt/vtt/json…）、压缩包（zip/7z/tar.gz）。

## 架构

```
lanreel/
├─ server/                 零依赖 Node 服务
│  ├─ index.js             HTTP 入口、静态与页面路由（含机主门页）、优雅退出、启动横幅
│  ├─ config.js            端口 / 数据目录 / 体积上限 / 机主口令（均可用环境变量覆盖）
│  ├─ routes.js            REST 路由表（入库、状态、备注、分享、流、SSE、导出、机主口令）
│  ├─ store.js             内存数据模型 + JSON 落盘（原子写）+ 变更事件 + 操作流水
│  ├─ media.js             HTTP Range 分段供片、静态资源、安全响应头
│  ├─ bus.js               SSE 广播中心（25s 心跳）
│  └─ util.js              路径净化、MIME/类型表、请求体流式落盘、本机与口令判定
├─ public/
│  ├─ index.html           素材库（机主）
│  ├─ share.html           分享页（局域网同事）
│  ├─ css/tokens.css       ★ 设计令牌：颜色 / 字号 / 间距 / 圆角 / 阴影 / 动效
│  ├─ css/base.css         重置、排版原语、布局工具类、关键帧库
│  ├─ css/components.css   组件层（按钮、卡片、药丸、弹层、菜单、操作坞、放映厅）
│  ├─ css/views.css        页面层（首屏、入库区、素材夹卡、分享头）
│  ├─ css/error.css        门页 / 错误页专用（服务端直出，CSP 下不能内联样式）
│  └─ js/                  原生 ES Module
│     ├─ dom.js            h() 渲染原语、格式化、Toast、弹层、「更多」菜单
│     ├─ api.js            接口封装（XHR 上传以获取真实进度、评审写操作带分享码）
│     ├─ uploader.js       文件夹展开、去重、并发上传、进度事件
│     ├─ backfill.js       给挂载的视频/音频/图片补封面、时长与尺寸（复用同源抓帧）
│     ├─ inspect.js        浏览器侧时长/分辨率探测与封面抓帧
│     ├─ review.js         评审网格：筛选、勾选、批量状态、增量重绘
│     ├─ theater.js        放映厅：播放 + 状态 + 备注
│     ├─ identity.js       署名
│     ├─ sync.js           SSE 客户端
│     ├─ statuses.js       状态枚举（前后端共用同一份定义）
│     ├─ app.js            素材库页控制器
│     ├─ share.js          分享页控制器
│     └─ gate.js           门页：输机主口令换一枚机主 Cookie
└─ data/                   运行时生成
   ├─ db.json              素材夹 / 素材 / 备注 / 操作流水 + 机主口令（原子写）
   ├─ blobs/<xx>/<sha256>  复制入库的内容，按哈希去重
   └─ media/<夹ID>/        素材硬链接 + 浏览器抓的封面（挂载模式只有封面）
```

**数据流**：浏览器 `File` → XHR 原始字节 → `for await (chunk of req)` 直接写盘 → 更新 `db.json` → 触发 `change` 事件 → SSE 广播 → 所有打开的页面增量重绘。

**供片**：`/api/stream/:id` 支持 `Range`、`HEAD`、`416`，响应头带 `Accept-Ranges` 与 `immutable` 缓存，因此拖动进度条是本地直读，秒级响应且重复观看不再重新拉取。

## 设计令牌（Design Tokens）

统一在 `public/css/tokens.css`，组件层禁止写死数值。**全站只用平色**：单一强调色 + 中性灰阶，不使用任何渐变、扫光或彩色光晕；亮色为默认主题，放映厅区域两种主题下都保持深色。

| 组 | 令牌 | 取值 |
| --- | --- | --- |
| 强调色 | `--accent`、`--accent-hover`、`--accent-ink` | 单一 teal：亮色 `#0f766e` / 暗色 `#2dd4bf`，及其按下态与前景色 |
| | `--accent-soft`、`--accent-line` | 强调色的浅底与描边（用于入库区、选中态） |
| 中性色 | `--canvas`、`--surface-1..3`、`--surface-glass`、`--line-soft/strong` | 页面 → 卡片 → 描边 |
| | `--ink-100/80/60/40/20` | 透明度阶梯文本 |
| | `--stage` | 放映厅底色（固定深色，保证观看聚焦） |
| 语义色 | `--tone-info/success/warn/danger/neutral` | 蓝 / 绿 / 琥珀 / 玫红 / 石板 |
| 状态色 | `--status-unset/todo/short/revise/drop` | 映射到语义色，跨主题不变 |
| 字号 | `--text-2xs → --text-3xl`、`--text-hero` | 11px 起，`clamp()` 流式放大 |
| | `--leading-tight/snug/normal`、`--tracking-tight/wide` | 行高与字距 |
| | `--type-eyebrow/label/body/title/display` | 一行式排版角色简写 |
| 间距 | `--space-1 → --space-12` | 4px 基准的 12 级阶梯 |
| | `--gutter`、`--stack`、`--maxw`、`--rail` | 页面级留白（本轮整体放宽） |
| 圆角 | `--radius-xs → --radius-2xl`、`--radius-full` | 6 / 10 / 12 / 16 / 22 / 28 / 999px（收敛上限，大面积更平整） |
| 阴影 | `--shadow-1 → --shadow-5` | 冷灰低透明度，只做层次不做光晕 |
| | `--inner-hi`、`--inner-lo` | 极淡的内高光/内暗线 |
| 动效 | `--ease-out/in-out/spring/glide` | 4 条贝塞尔曲线，`spring` 用于按压与弹出 |
| | `--duration-1 → --duration-5` | 120 / 200 / 340 / 560 / 900ms |
| | `--stagger`、`--motion-hover/press/enter` | 列表错峰入场与位移原语（动效全部保留，仅去掉扫光类装饰） |
| 其他 | `--blur-glass`、`--ring`、`--z-base..toast` | 毛玻璃、焦点环（强调色半透明外圈）、层级 |

`prefers-reduced-motion: reduce` 时，动效令牌整体降到 1ms 并关闭循环动画。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/health` | 版本、连着 SSE 的页面数、`local`（请求方是否本机）、`owner`（请求方是否机主）、局域网地址、素材合计与 `data/` 实际占用（按 inode 去重）、生效的体积上限 |
| `GET` | `/api/owner` | 明文机主口令，**仅限本机**（其他设备只能从 `/api/health` 知道自己是/不是机主） |
| `POST` | `/api/owner/unlock` | `{token}` 验证机主口令，通过则种 `lanreel_owner` Cookie（`HttpOnly; SameSite=Strict`，一年） |
| `POST` | `/api/owner/lock` | 清掉本机浏览器上的机主 Cookie |
| `GET` / `POST` | `/api/bundles` | 素材夹列表 / 新建，**机主**；列表里挂载夹带 `root` 源目录 |
| `GET` / `PATCH` / `DELETE` | `/api/bundles/:ref` | 详情（含条目）/ 改名 / 删除，**机主**；删除只清 `data/` 里的副本与封面，挂载素材的原始文件不动 |
| `GET` | `/api/bundles/:ref/export?fmt=csv\|json` | **机主**。评审表下载：CSV 带 BOM（Excel 直接双击不乱码），列为序号 / 文件名 / 相对路径 / 类型 / 时长 / 体积 / 状态 / 标注人 / 标注时间 / 备注（含时间码）/ 源文件；JSON 额外含 `log` 操作流水 |
| `POST` | `/api/bundles/:ref/items?name&path&size&duration&width&height` | 请求体即文件字节，流式落盘并计算内容哈希，**机主** |
| `POST` | `/api/mounts` | `{path, name}` 零拷贝挂载本机目录，**仅限本机**；返回体带 `duplicates` 副本提示 |
| `POST` | `/api/pick-folder` | 让本机弹出系统文件夹选择器，返回 `{path}` 或 `{cancelled:true}`，**仅限本机** |
| `POST` | `/api/bundles/:ref/rescan` | 重新扫描挂载目录：补新文件、去已删文件、把回来的文件取消「源文件丢失」标记（`{added, removed, revived, total}`），保留已有状态与备注（**仅限本机**） |
| `POST` | `/api/items/:id/poster` | 上传浏览器抓取的视频封面（JPEG，≤8MB），**机主** |
| `POST` | `/api/items/status` | `{ids[], status, by}` 批量打状态：机主不限夹子；其他请求要带 `x-share-token`，且所有 id 必须属于该夹子 |
| `PATCH` / `DELETE` | `/api/items/:id` | 改名 / 删除单条，**机主**（评审同事没有这一项） |
| `POST` / `DELETE` | `/api/items/:id/notes[/:noteId]` | 新增 / 删除备注，作用域同上；`t` 为可选时间点（秒，保留一位小数，非法或缺省存 `null`），删除只有作者本人可以 |
| `GET` | `/api/share/:token` | 分享视图载荷（不含本机绝对路径） |
| `GET` | `/api/stream/:id` | Range 供片，`?download=1` 转附件下载；挂载素材读不到文件时返回 404 并把该条标成 `missing` |
| `GET` | `/api/poster/:id` | 封面（图片类直接回原图） |
| `GET` | `/api/events?bundle=` | SSE 实时变更流 |

页面路由：`/` 素材库（非机主访问返回一页机主口令输入）、`/s/<分享码>` 分享页。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `U` | 选择本地文件夹入库 |
| `/` | 聚焦搜索 |
| `Shift` + 点选 | 从上次勾选连选到当前一条 |
| `⌘` / `Ctrl` + `A` | 全选当前筛选结果 |
| `Esc` | 取消选择；没有选中项时关闭弹层 |

## 安全与边界

- **文件不出本机**：没有任何外部上传、第三方脚本或 CDN；CSP 为 `default-src 'self'`，样式与动态样式分别限制为同源与 CSSOM。
- **链接即权限**：分享码是 16 位随机 base64url，素材 ID 同样不可枚举；素材文件以随机 ID 命名存放，用户提供的文件名与相对路径都经过净化（剥离 `..`、路径分隔符与控制字符），无法穿越目录。
- **三种身份，各管一段**：

  | 身份 | 怎么认定 | 能做什么 |
  | --- | --- | --- |
  | 机主 | 运行 LanReel 的这台电脑，或带正确的机主口令（Cookie / `x-owner-token`），或 `LIBRARY_FROM_LAN=1` | 全部：建/改名/删素材夹、上传入库、导出评审表、给单条素材改名与删除 |
  | 评审同事 | 打开你发的 `/s/…` 链接（浏览器自动带上这条链接的分享码） | 只看这一个夹子：观看、打状态、写备注、删自己的备注 |
  | 同网路人 | 既没链接也没口令 | 什么都做不了：素材库 403，写接口 403 |

- **评审写操作按夹子收口**：`/api/items/status`、`/api/items/:id/notes` 对非机主请求必须带 `x-share-token`，而且每一条素材都要属于那个夹子，否则 403。改名、删除单条、上传封面则整个收归机主——以前这些接口对局域网完全敞开，拿到一条链接的人就能凭素材 ID 改名甚至删除 `data/` 里的副本。
- **挂载、重新扫描、文件夹选择器只允许本机**：这三样会读目录结构、动磁盘、在你的屏幕上弹原生对话框，所以口令也不放行。它们校验的是来源地址属于本机自身——包括 `127.0.0.1`、`::1`，也包括这台机器自己的网卡地址（用 `http://192.168.1.12:8080` 访问时同样放行，否则机主会被误挡）。判本机只看真实 socket 地址，伪造的 `X-Forwarded-For` 不放行。
- **机主口令**：首启随机生成 12 位 base64url（约 72 位熵），启动横幅里印着，「快捷键」面板里也能复制；设 `OWNER_TOKEN` 可固定。在其他设备上打开 `/` 会看到一页口令输入框，验证通过后种一个 `HttpOnly; SameSite=Strict` 的 Cookie，一年有效；比对走 `crypto.timingSafeEqual`。
- **删除永不碰原始文件**：挂载模式的素材只保存路径，删除素材夹或单条素材只会解除分享并清掉我们自己的封面文件——确认框里也照这个说，不再笼统写「本机文件会被移除」。
- **口令不等于访问控制的全部**：分享链接仍然是「知道链接就能看」，同网段任何人都能打开 `/s/…`（这是「同网即开」的取舍）。要真正限制访问，请把 `HOST` 设为 `127.0.0.1`，或放到反向代理后面加认证。
- **可播放性取决于编解码**：H.264/VP9/AV1 的 mp4/webm/mov 可直接播；HEVC、ProRes、mkv 等建议转码后再入库（播放器会显示原生错误，其余功能不受影响）。
- 备注与状态的署名保存在浏览器本地，删除浏览器数据后无法再删除他人备注（服务端仅允许同名作者删除自己的备注）。
- 时间码只对视频 / 音频生效；图片与文档的备注一律记为「整体备注」。

## 已知限制

- **「上传」一定会复制一份**，这不是实现取舍而是 Web 平台限制：浏览器不提供文件的绝对路径，服务端拿不到原文件位置，只能接收字节。想完全不复制，请用「挂载本机目录」（浏览… 一键选目录）。
- 单进程、内存数据模型 + JSON 落盘，面向个人 / 小团队评审场景，不是多租户网盘。
- 去重只对**新入库**的内容生效：1.2 之前已复制进 `data/media/` 的旧文件仍是每夹一份，需要的话把它们重新入库一次即可归并到 `blobs/`。
- 挂载模式要求源目录保持在原位：移动或改名后这些条目会被标成「源文件已丢失」（开机校验一次，供片失败当场补记），文件放回原位后点「重新扫描」即恢复；在外的时间窗口里，已经看过这条素材的浏览器还可能凭 7 天的 `immutable` 缓存继续放到旧画面。
- 封面抓取依赖浏览器解码能力：浏览器放不了的视频只有占位图，没有缩略帧。
- 没有断点续传：上传中断的文件会在下次同名同体积上传时被覆盖或跳过，服务端启动时清理未完成的入库记录。
